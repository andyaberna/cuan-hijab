SOP HARIAN — Step by Step

Hari 1: LAUNCH

Waktu: 23:30 WIB malam sebelumnya

  1. Buka Ads Manager → Create Campaign
  2. Pilih objective: Sales → Purchase
  3. Set campaign name: [SANDBOX] CuanHijab ABO Test
  4. Budget type: ABO
  5. Buat 5 adset sesuai tabel di atas
  6. Setiap adset:
  • Budget: Rp30.000/hari
  • Targeting: Broad, 25-55, Perempuan, Indonesia
  • Placements: Advantage+
  • Upload 3 visual + 2 primary text + 2 headline (DCO ON)
  • Masukkan link checkout + UTM
  1. Schedule: Start besok 00:00 WIB
  2. Review → Publish
  3. Cek Event Manager — pastikan pixel firing

Setelah publish: JANGAN SENTUH.

Hari 1–3: LEARNING PHASE (Jangan Sentuh!)

Ini aturan keras. Selama 72 jam pertama:

  • Jangan pause adset
  • Jangan edit teks/visual
  • Jangan ubah budget
  • Jangan tambah adset
  • Jangan ganti targeting

Kenapa? Learning phase Meta sangat sensitif. Perubahan sekecil apapun = reset total. Data jadi sampah.

Yang boleh dilakukan:

  • Lihat dashboard (read-only)
  • Screenshot metrik untuk catatan
  • Siapkan angle cadangan untuk minggu ke-2

Hari 4: EVALUASI PERTAMA

Waktu: Pagi, 08:00-09:00 WIB

Buka Ads Manager → pilih kolom:

Kolom Cara Lihat
CTR (Link Click-Through Rate) Columns → Performance → CTR
CPM (Cost per 1000 Impressions) Columns → Performance → CPM
CPA (Cost per Purchase) Columns → Performance → Cost per Result
Link Clicks Columns → Performance → Link Clicks
Purchases Columns → Performance → Results

Tabel Keputusan — Per Adset:

Metrik Benchmark Keputusan

Hari 5–6: MONITOR

Waktu: Pagi 08:00 + Sore 17:00 (2x sehari)

Cek metrik yang sama. Update tabel.

Kalau ada adset yang di-KILL di hari 4:

  • Matikan adset tersebut
  • Budget-nya JANGAN dipindah ke adset lain (biar data bersih)
  • Total spend turun — itu normal

Kalau semua adset masih jalan:

  • Perhatikan tren: CTR naik atau turun?
  • CPA stabil atau melonjak?
  • Ada purchase baru?

Hari 7: FINAL DECISION

Waktu: Pagi 08:00 WIB

Ini hari penentuan. Buka data 7 hari penuh.

Skenario A: Ada 1-2 Winner (CPA < Rp25K) → Tandai winner → Catat Post ID iklan winner (klik ad → lihat Post ID di URL) → Besok masuk Phase 2: Scale

Skenario B: Ada yang CTR bagus tapi belum purchase → Cek LP: apakah ada masalah loading/checkout? → Lanjut 3 hari lagi (sampai hari ke-10) → Kalau tetap gak convert → kill, buat angle baru

Skenario C: Semua jelek (CTR < 1.5%, CPA > Rp40K) → Matikan semua → Analisa: angle mana yang paling mendekati? → Buat 3 angle baru dari Ad 6/7/8 (Scale Up, Brand Sendiri, Omzet Konsisten) → Ulangi sandbox dengan budget yang sama

Diagnostic Matrix — Kalau Hasilnya Jelek

Jangan langsung bilang "ads-nya jelek". Baca datanya dulu:

Gejala Kemungkinan Masalah Yang Harus Dilakukan
CTR rendah di Adset 1 (Oblivious) Hook supplier zonk kurang tajam, visual gak bikin berhenti Rewrite hook — perjelas gejala supplier, buat 3 hook baru
CTR rendah di Adset 2/4 (Frustrated) Pain point kurang spesifik atau udah terlalu sering dipakai Ubah angle: coba "false solution" atau "salah diagnosis"
CTR rendah di Adset 3 (Hopeful) Framework/credential belum terasa relevan Ganti hook ke "simpler process" atau "anti nebak"
CTR bagus tapi LP gak convert Ad dan LP gak nyambung, LP lambat, atau clickbait Samakan headline LP dengan hook ad, cek speed
CTR + LP bagus tapi checkout jelek Trust kurang, offer lemah, CTA kabur, friction checkout Audit LP: naikkan trust, sederhanakan CTA
Adset 5 (Fan) gak gerak Audience belum cukup warm, offer kurang kuat Tunggu data retarget — jangan scale Fan ke cold

Cara Copy Post ID

  1. Buka campaign Sandbox
  2. Klik ad yang menang
  3. Di preview, klik "Facebook Post with Comments"
  4. Copy angka di URL setelah /posts/
  5. Di campaign Scale, pilih "Use Existing Post" → paste Post ID

Ini penting — likes, comments, shares dari Sandbox ikut terbawa. Social proof = conversion booster.

Budget Scaling Rules


Minggu 1:  Rp150.000/hari (baseline)
Minggu 2:  Rp180.000/hari (+20%) — HANYA kalau ROAS > 2x
Minggu 3:  Rp216.000/hari (+20%)
Minggu 4:  Rp260.000/hari (+20%)

Aturan naik budget:

  • Naikkan MAKSIMAL 20% per 2 hari
  • Cek ROAS sebelum naikkan — harus > 2x
  • Kalau ROAS turun di bawah 1.5x → turunkan budget 30%, tunggu 3 hari
  • Jangan naikkan budget lebih dari 1x dalam sehari

Kalau CPA konsisten di bawah Rp25K → profit Rp144K/hari dari spend Rp150K. ROAS 1.96x. Kalau CPA di bawah Rp20K → profit Rp200K+/hari. Sweet spot.

Contingency Plan

Kalau CPA Meledak (> Rp40K selama 3 hari)

  1. Pause semua adset kecuali yang CPA paling rendah
  2. Cek LP: loading speed, checkout flow, mobile experience
  3. Cek frequency: > 3.0 = audience jenuh
  4. Buat 3 angle baru dari Ad 6/7/8
  5. Launch sandbox baru dengan budget Rp90K/hari (3 adset × Rp30K)

Kalau Ad Ditolak Meta

  1. Baca rejection reason di Ads Manager
  2. Biasanya: "misleading claims" atau "personal attributes"
  3. Fix: hapus kalimat yang menyerang personal, ganti ke blame sistem
  4. Resubmit — biasanya approved dalam 24 jam
  5. Kalau tetap ditolak → appeal, atau rewrite total

Kalau Pixel Mati

  1. PAUSE campaign segera — jangan buang budget tanpa tracking
  2. Cek Event Manager → Test Events
  3. Buka LP di browser → cek apakah pixel firing
  4. Hubungi ScaleV support kalau pixel error
  5. Baru resume campaign setelah pixel confirmed hijau
